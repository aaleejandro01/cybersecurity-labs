# Blue Team & Security Operations Projects

> Practical cybersecurity labs focused on Blue Team operations, vulnerability management, network monitoring, cryptography, and secure communications.

## Tech Stack & Tools
* **Monitoring & IDS:** Suricata, Splunk, Wireshark
* **Vulnerability Management (DAST):** OpenVAS, OWASP ZAP, Nikto
* **Cryptography & Security:** OpenSSL, TLS 1.3, HMAC-SHA256
* **Infrastructure & OS:** Linux (Kali), Docker, Bash Scripting
* **Programming:** Python, C#, .NET

## Projects & Academic Labs Overview

* **Blue Team Operations & IDS:** Deployment of **OpenVAS** via Docker for vulnerability management and configuration of **Suricata** with custom rules for anomalous traffic monitoring. Network traffic analysis and encryption verification using **Wireshark**.
* **Cryptography & Secure Communications:** Development of Python client-server simulators implementing secure channels with **TLS 1.3** and **OpenSSL** certificates. Application of integrity validation via **HMAC-SHA256** to mitigate *Man-in-the-Middle* and *Replay* attacks.
* **Pentesting & Web Hardening:** Security audits (DAST) on vulnerable applications (Mutillidae II) using **OWASP ZAP**, **Kali Linux**, and **Nikto**. Controlled execution of exploits for privilege escalation and server hardening applied to Linux systems using **Lynis**.

## Repository Structure

* `📁 01-Integridad-HMAC-MITM/` - Python scripts and technical report on message integrity and MITM mitigation.
* `📁 02-Secure-BYOD-TLS/` - Implementation of TLS 1.3 client-server architecture with OpenSSL.
* `📁 03-Auditoria-Vulnerabilidades-Web/` - DAST security audit and mitigation plans.
* `📁 04-Monitorizacion-IDS-OpenVAS/` - IDS rule configuration and vulnerability scanning.
* `📁 05-Pentesting-Sistemas/` - System exploitation and vulnerability discovery.

*(Note: Each folder contains the custom scripts used and a detailed PDF Technical Report of the laboratory).*
